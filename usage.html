이 앱들은 개인 개발자가 무료로 배포하는 도구입니다. 기기·Android 버전·파일 형식·외부 서비스 상태에 따라 오류, 표시 차이 또는 작업 중단이 생길 수 있습니다. 모든 환경의 호환성, 결과의 완전성·정확성, 지속적인 지원·업데이트를 보장하지 않습니다.

중요한 데이터는 사용 전에 앱과 별개의 위치에 백업하세요. 중요한 문서 표시·계산·전송·동기화 결과는 원본과 대조해 확인하세요. 앱의 복구 기능이나 외부 서비스의 이력만을 유일한 백업으로 사용하지 마세요.

이 보증 제한은 관계 법령이 허용하는 범위에서 적용됩니다. 개발자의 고의 또는 중대한 과실에 대한 책임 등 관계 법령에 따라 배제·제한할 수 없는 책임과 이용자의 권리는 이 안내로 배제·제한되지 않습니다. 포함된 오픈소스의 저작권·라이선스 조건도 그대로 적용됩니다.

파일 관리자 · 백업·삭제·덮어쓰기·충돌

앱은 파일 전체를 자동으로 백업하지 않습니다. 복사·이동·이름 변경·삭제 전 기기와 연결된 서버의 중요한 파일을 별도로 보관하세요.

삭제는 선택한 기기 폴더 또는 연결한 서버에 반영됩니다. Google Drive는 휴지통으로 보내지만, 기기·WebDAV의 삭제와 복구 가능 여부는 저장소에 따라 다르며 앱 자체 휴지통이나 복원을 보장하지 않습니다. 폴더 삭제는 안의 파일에도 영향을 줄 수 있습니다.

같은 이름의 대상이 있으면 복사·이동·이름 변경을 중단하며 자동 덮어쓰기나 내용 병합을 하지 않습니다. 이름을 바꾸거나 두 파일을 직접 확인하세요. 다른 기기나 앱이 동시에 파일을 바꾸면 상태가 달라질 수 있으므로 같은 파일의 동시 작업은 피하세요.

이동은 복사 결과를 확인한 뒤 원본 삭제를 시도합니다. 취소·연결 끊김·작업 실패 시 원본과 대상 양쪽을 확인하세요. 연결 해제·앱 삭제는 외부 파일의 백업이나 복구를 대신하지 않습니다.

Vault Sync

Vault Sync · 백업·삭제·덮어쓰기·충돌

첫 연결과 동기화 전 Obsidian 보관함을 앱 밖의 별도 위치에 백업하세요. GitHub 이력과 앱의 복구 사본만을 유일한 백업으로 사용하지 마세요. 동기화 중에는 휴대전화와 PC에서 같은 노트의 편집을 잠시 멈추세요.

첫 동기화는 양쪽 파일을 합칩니다. 이후에는 한쪽의 수정·삭제가 동기화 결과에 따라 다른 쪽에도 반영될 수 있습니다. 단순 동기화도 기존 파일 내용을 교체할 수 있으므로 변경 목록과 삭제 예정 항목을 확인하세요. 숨김 파일·폴더는 동기화하지 않습니다.

양쪽에서 같은 노트를 수정했거나 삭제와 수정이 충돌하면 자동으로 한쪽을 덮어쓰지 않고 확인을 요청합니다. '둘 다 보존하고 동기화'를 선택하면 양쪽 수정 내용을 보존합니다. 휴대전화 내용을 유지하고 GitHub 버전은 별도 충돌 사본으로 보관하며, 삭제와 수정의 충돌은 수정된 내용을 남깁니다. 자동 문장 병합은 하지 않으므로 충돌 사본을 직접 비교·정리하세요.

반영 전후 복구 자료는 앱 내부에 보관됩니다. 앱 삭제·데이터 초기화 전에 연결 설정의 '복구 사본 저장'으로 ZIP을 앱 밖에 저장하세요. 연결 해제는 보관함과 GitHub 파일 자체를 삭제하지 않습니다. 작업 중 파일이나 원격 저장소가 바뀌어 중단되면 먼저 복구 사본을 저장하고 현재 파일을 확인하세요.
