Vault Sync

Vault Sync · 백업·삭제·덮어쓰기·충돌

첫 연결과 동기화 전 Obsidian 보관함을 앱 밖의 별도 위치에 백업하세요. GitHub 이력과 앱의 복구 사본만을 유일한 백업으로 사용하지 마세요. 동기화 중에는 휴대전화와 PC에서 같은 노트의 편집을 잠시 멈추세요.

첫 동기화는 양쪽 파일을 합칩니다. 이후에는 한쪽의 수정·삭제가 동기화 결과에 따라 다른 쪽에도 반영될 수 있습니다. 단순 동기화도 기존 파일 내용을 교체할 수 있으므로 변경 목록과 삭제 예정 항목을 확인하세요. 숨김 파일·폴더는 동기화하지 않습니다.

양쪽에서 같은 노트를 수정했거나 삭제와 수정이 충돌하면 자동으로 한쪽을 덮어쓰지 않고 확인을 요청합니다. '둘 다 보존하고 동기화'를 선택하면 양쪽 수정 내용을 보존합니다. 휴대전화 내용을 유지하고 GitHub 버전은 별도 충돌 사본으로 보관하며, 삭제와 수정의 충돌은 수정된 내용을 남깁니다. 자동 문장 병합은 하지 않으므로 충돌 사본을 직접 비교·정리하세요.
