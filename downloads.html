앱별 다운로드 횟수

GitHub Releases의 APK 다운로드 횟수입니다. 사용자 수나 설치 수가 아니며, 재다운로드와 검증용 다운로드도 포함됩니다.

Releases 주소를 사용하기 시작한 이후만 집계합니다. 기존 Pages 주소·구형 ‘내 앱’·앱에 내장된 APK를 통한 다운로드나 설치는 포함하지 않습니다.

개발자가 사용자 식별자·IP 주소·기기 정보를 별도로 수집하는 추적 코드는 사용하지 않습니다. 이 화면은 GitHub의 공개 집계값만 읽습니다. GitHub 자체의 서비스 운영 기록은 별개입니다.
